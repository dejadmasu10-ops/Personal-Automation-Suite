# Personal Automation Suite

A Python automation project that combines file organization, weather logging, and email notifications into one application.

## Features

- Organizes files automatically by file type
- Fetches current weather using OpenWeather API
- Saves weather data to a CSV file
- Sends automated emails using Gmail SMTP
- Provides a Streamlit web interface
- Includes error handling for file, network, and email operations

## Technologies Used

- Python
- Streamlit
- Requests
- Pandas
- python-dotenv
- OpenWeather API
- Gmail SMTP
